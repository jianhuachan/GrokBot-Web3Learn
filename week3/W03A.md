# W03A：地址、整数、函数、可见性、view、映射、调用者身份和权限

## 1. Subcurrency Example（Coin 合约）的四个重点

1. **`address`**：`address public minter;`，记录铸币人地址。`address` 是 160 位的值，不能做算术运算，可以存合约地址或外部账户地址；`public` 会自动生成读取函数。
2. **`mapping`**：`mapping(address => uint) public balances;`，余额表，写法是 `mapping(键类型 => 值类型)`。查 `balances[某个地址]` 就能拿到该地址当前余额，没写入过的地址默认是 0。
3. **`msg.sender`**：当前调用者的地址。`constructor` 里 `minter = msg.sender;` 表示谁部署谁就是 minter；`send` 里表示从谁的余额扣钱。
4. **`require`**：条件和权限检查，不满足就回滚。
   - `mint`：`require(msg.sender == minter);`，只有 minter 能铸币。
   - `send`：`require(amount <= balances[msg.sender], InsufficientBalance(amount, balances[msg.sender]));`，检查余额是否足够。

**`minter` 的一生：** 声明 → `constructor` 里赋值为部署者 → `mint` 里拿来和 `msg.sender` 对比。这就是“地址 + 调用者身份 + 权限”连在一起的样子。

## 2. 逐行解释 Coin 合约

- `pragma solidity ^0.8.26;`：用 0.8.26 及以上、不到 0.9 的编译器。
- `address public minter;`：存铸币人地址。
- `mapping(address => uint) public balances;`：余额表。
- `event Sent(address from, address to, uint amount);`：转账事件声明，给前端监听，本身不改余额。
- `constructor()`：只在部署时运行一次，`minter = msg.sender;`。
- `mint(address receiver, uint amount)`：只有 minter 能调用，给 `receiver` 增加新币。
- `error InsufficientBalance(uint requested, uint available);`：自定义错误，说明“要了多少、实际有多少”。
- `send(address receiver, uint amount)`：任何人转出自己已有的币；先检查余额，再从自己扣、给对方加，最后 `emit Sent(...)`。

## 3. 自定义错误与 require

- `require` 的三种写法：
  - `require(bool)`：回滚时不带任何数据。
  - `require(bool, string)`：回滚时带 `Error(string)`。
  - `require(bool, error)`：回滚时带自定义错误和它的参数。
- `InsufficientBalance(amount, balances[msg.sender])` 不是一段字符串，而是自定义错误，两个参数分别对应 `requested` 和 `available`。
- 官方文档：[Custom Errors](https://docs.soliditylang.org/en/latest/contracts.html#custom-errors)、[Error handling: Assert, Require, Revert and Exceptions](https://docs.soliditylang.org/en/latest/control-structures.html#error-handling-assert-require-revert-and-exceptions)。

## 4. 练习：自己写 Storage Example 的 set / get

在 Remix（remix.ethereum.org）里自己写：

```solidity
// SPDX-License-Identifier: GPL-3.0
pragma solidity >=0.4.16 <0.9.0;

contract SimpleStorage {
    uint storedData;

    function set(uint x) public {
        storedData = x;
    }

    function get() public view returns (uint) {
        return storedData;
    }
}
```

**结果：**
- 编译通过。编辑器估算 `set` 约 22492 gas，`get` 约 2431 gas。
- 部署到 Remix VM，调用 `set(42)`，再调用 `get()`，读回 `0: uint256: 42`，值确实存进了合约存储。✅
- 记录里三种操作：
  - **constructor**：部署交易，有 hash。
  - **set(uint256)**：写入交易，有 hash，改了状态。
  - **get()**：标着 **CALL**，只读，没有交易 hash，不花 gas（即 `eth_call`）。
- Remix 里的文件存在 Remix 网页的工作区（浏览器存储），不在 Mac 的文件夹里。
