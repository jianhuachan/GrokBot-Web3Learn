# W01-F 第 1 周 Review

## 1. 解释（15 分钟）
**我的回答**：钱包本身不保存代币。地址相当于公钥，别人转账给我或我转给别人都要填地址，类似银行卡账号；私钥相当于银行卡密码。测试网可以用来测试 transaction 的流程，学习 transaction。

**Review**：✅ 正确。补充：钱包保存的是私钥；私钥算出公钥，公钥再算出地址，所以地址是由公钥推导出来的，不完全等于公钥。

## 2. 独立操作（45 分钟）
交易：https://sepolia.etherscan.io/tx/0x3d7821fc6d086f3d80b047bb1f66f234c86f6ee356e86e42006e630e8e03cf3e

| 字段 | 值 |
|---|---|
| 状态 | 成功（status = 1） |
| From | 0x95612fb5291D840F0501a36Cc381732C2E682Ff7 |
| To | 0xd1F0D8744a82613d5EC772efa0B6cAe6B8aA3B32（代币合约本身） |
| Value | 0 ETH |
| 调用函数 | approve（input 开头 0x095ea7b3） |
| gasUsed | 127,859 |
| Gas 价格 | 19 wei（0.000000019 Gwei） |
| 手续费 | 2,429,321 wei = 0.000000000002429321 ETH |
| Nonce | 2275 |
| 区块 | 12090922 |

**Review**：数字全部正确。❌ 交易类型判断错误：这不是"转 0 ETH 给 0xd1F0…3B32"。To 是代币合约，交易调用的是 `approve`，作用是授权 0xbeb66f7bc8e9e9007fc1bc6a1161d7470a1615dd 最多动用 7,600,000,000 个最小单位的该代币。没有代币被转走，只产生一条 Approval 日志。
**要点**：To 是合约时，要看 Input Data 里调用的是哪个函数，再看 Logs，才能判断交易在做什么。

## 3. 异常检查（20 分钟）
**我的回答**：切换网络显示不同余额，是因为钱包有多家银行，每张卡里额度不同。账号私钥不能放进仓库。

**Review**：结论正确，比喻可改进。同一个地址在所有 EVM 网络通用，但每个网络是一本独立的账本，钱包只是去不同账本查余额。不能放进仓库的还有：助记词、包含私钥或 RPC 密钥的 `.env` 文件。
