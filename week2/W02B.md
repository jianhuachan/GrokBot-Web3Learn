# W02-B 用 Scaffold-ETH 2（Hardhat 路线）搭建本地链

> 本文件为第 2 周任务 B（W02-B）的学习笔记。

Scaffold-ETH 2 是一个 Next.js + Hardhat 的起步模板。

## 创建项目
- 用 `npx create-eth@latest` 创建项目，Solidity 框架选择 **Hardhat**。

## 1. 为什么要记录 Node 版本
- 不同 Node 版本下，依赖包的行为可能不一样。
- 出问题时，第一件事就是检查 Node 版本是否匹配。
- 本机 Node 版本：v24.15.0（官方要求 >= v20.18.3）

## 2. 包管理器
- 本项目使用 **yarn**。
- 注意：`node_modules` 不是包管理器，它只是存放已安装依赖包的文件夹。
- 项目实际使用的 yarn 版本：**4.13.0**，由根目录 `.yarnrc.yml` 的 `yarnPath: .yarn/releases/yarn-4.13.0.cjs` 锁定（根目录 `package.json` 第 60 行 `packageManager: yarn@4.13.0` 也写了同一版本）。
- 全局 yarn 是 1.22.22（通过 corepack 启用），进入项目后会自动切换到 4.13.0。

## 3. 三个主要命令（各开一个终端，同时运行）
| 命令 | 作用 |
|---|---|
| `yarn chain` | 启动本地 Hardhat 节点（本地链） |
| `yarn deploy` | 部署示例合约 |
| `yarn start` | 启动前端（http://localhost:3000） |

## 4. 实际操作步骤
- ✅ `npx create-eth@latest`（选择 Hardhat）
- ✅ `yarn install`
- ✅ `yarn chain`
- ✅ `yarn deploy`
- ✅ `yarn start`

## 5. 排错：HHE202
- 现象：`yarn deploy` 报 HHE202，`hardhat-deploy` 需要 `@rocketh/node` ^0.22.4，但安装的是 0.19.22。
- 原因：`hardhat-deploy` 版本写的是 `^2.0.6`，自动装成了 2.3.0，而 2.3.0 需要 rocketh 0.22。
- 解决：在 `packages/hardhat` 里运行 `yarn add -E hardhat-deploy@2.0.6` 固定版本，之后部署成功。
- 部署结果：YourContract 地址 `0x67d269191c92caf3cd7723f116c85e6e9bf55933`

## 6. JSON-RPC 与交易流程（复习）
- 请求字段：`jsonrpc`（2.0）、`id`、`method`、`params`。
- `eth_getBalance` 返回十六进制的 wei 余额。
- 交易流程：钱包签名 → RPC 广播 → 交易哈希 → 打包进区块 → 回执 status（1 = 成功）。

## 7. Debug Contracts 页
- 列出已部署的合约，可以直接调用合约函数。
- 部署之前这个页面是空的。

## 8. 本地链默认参数
| 项目 | 值 |
|---|---|
| RPC URL | `http://127.0.0.1:8545` |
| 链 ID | 31337（十六进制 0x7a69） |
| 预置账户 #0 | `0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266`，初始 10000 ETH |

⚠️ 预置账户的私钥是公开的，只能在本地链上使用。

## 9. MetaMask 连接本地链
- ✅ 添加网络：名称 Hardhat Local、RPC `http://127.0.0.1:8545`、链 ID 31337、币种 ETH；区块浏览器留空。
- 黄色警告可以忽略：31337 也被 GoChain Testnet 用过，所以 MetaMask 建议改名。
- 自己的账户在本地链上一开始余额为 0（本地链是独立账本，和 Sepolia 不通用）。
- ✅ 通过 Faucet 从 `0xf39F…2266` 转 30 ETH 到 Account 1 `0x3270…3857`
  - 交易哈希：`0xca095f9d8e7efcfc3c39b0277009de3b16afc4a77bf23c1a6b281a1c091cf3f4`
  - 区块 36，status = 1（成功），gasUsed 21,000
  - 在本地区块浏览器查看了交易详情

## 10. 今日实操总结（重点）
1. 🚀 **启动三步，顺序固定**：`yarn chain` → `yarn deploy` → `yarn start`，各开一个终端。
   - 为什么重要：没有链就无法部署，没有部署前端就找不到合约。
2. ⚠️ **版本要对上**：Node v24.15.0；项目 yarn 实际是 **4.13.0**；`hardhat-deploy` 必须固定为 **2.0.6**，避免与 rocketh 0.22 的兼容问题（HHE202）。
   - 为什么重要：版本不对会直接部署失败，而且报错信息看起来跟版本无关，不容易查。
3. 📦 **包管理器是 yarn**，`node_modules` 只是安装后存放依赖包的文件夹。
   - 为什么重要：分清“工具”和“产物”，出问题时才知道该重装什么。
4. 🔗 **本地链参数**：Chain ID **31337（0x7a69）**，RPC `http://127.0.0.1:8545`。MetaMask 手动添加网络：网络名 Hardhat Local → RPC 填上面的地址 → 链 ID 31337 → 币种 ETH → 区块浏览器留空 → 保存并切换。
   - 为什么重要：Chain ID 或 RPC 填错，钱包会连到别的链，或者连不上。
5. 💰 **Hardhat 默认账户**：第一个账户 `0xf39F…2266`，初始 **10000 ETH**。
   - 为什么重要：本地所有测试 ETH 都从这里来；它的私钥是公开的，绝不能在主网使用。
6. 🚰 **Local Faucet 用的是 Hardhat 预置账户**（`0xf39F…`），和 MetaMask 当前账户不是同一个。
   - 为什么重要：MetaMask 显示 0 ETH 是正常的，要先用 Faucet 转钱过去。
7. 🐞 **Debug 页依赖部署**：只有 `yarn deploy` 成功后，才有合约地址和 ABI 可以显示。
   - 为什么重要：Debug 页是空的，通常说明部署没成功，应该先回去看 deploy 的输出。
8. 🔍 **查看交易记录**：用前端底部的 **Block Explorer**（`http://localhost:3000/blockexplorer`）查看转账和交易记录；`yarn chain` 终端也会打印每笔交易的哈希、区块号和 gas 用量。
   - 为什么重要：可以亲眼确认交易是否上链（status 1），把“签名 → 广播 → 打包”的流程对应到真实数据上。
