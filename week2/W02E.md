# W02E：用英文描述一次交易流程 + 环境恢复清单

## 1. 交易流程（英文，7 句）

1. First of all, I created a project with the Scaffold-ETH 2 CLI and started it locally with `yarn chain`, `yarn deploy` and `yarn start`.
2. Then the wallet (MetaMask) was connected to the local network (chain ID 31337).
3. After that, I used the local faucet to send 10 ETH to my Account 1 address and confirmed the transaction.
4. The RPC node at `http://127.0.0.1:8545` received the signed transaction and included it in a block.
5. A transaction hash was returned immediately, which I used to look up the transaction.
6. The receipt showed status 1, which means the transaction succeeded.
7. To restart, I run `yarn chain` first, then `yarn deploy`, then `yarn start`, and reset the MetaMask account because the local chain starts from zero again.

## 2. 环境恢复清单

在 `week2/scafflod-learn` 目录下，按顺序开三个终端：

1. `yarn chain`：启动本地链（RPC `http://127.0.0.1:8545`，chain ID 31337）
2. `yarn deploy`：重新部署合约（本地链重启后之前的合约和交易都没了）
3. `yarn start`：启动前端 `http://localhost:3000`
4. MetaMask：切到本地网络，在账户设置里“清除活动和 nonce 数据”（重置账户），避免 nonce 错误
