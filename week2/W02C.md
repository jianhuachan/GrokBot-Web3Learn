# W02C：本地转账结果与回执

> 本文件为第 2 周任务 C（W02-C）的学习笔记。

## 任务
- ✅ 将学习钱包（MetaMask）连接到本地网络 Hardhat Local
- ✅ 用已有测试资金的本地账户完成一笔转账

## 1. 网络参数（以 `yarn chain` 终端输出为准）
| 项目 | 值 |
|---|---|
| 网络名 | Hardhat Local |
| RPC URL | `http://127.0.0.1:8545` |
| 链 ID | 31337（0x7a69） |
| 币种 | ETH |

## 2. 操作步骤
- ✅ 重启本地链：`yarn chain`（链重启后数据会重置，余额归零）
- ✅ 启动前端：`yarn start`
- ✅ 用 Faucet 给 Account 1 转入测试 ETH
- ✅ 用 MetaMask 的 Send，从 Account 1 转 10 ETH 给 Account 2

## 3. 转账结果
| 字段 | 值 | 说明 |
|---|---|---|
| 交易哈希 | `0xbc211c6a4c4268497e9d29026d70894070ded1817b523d65ce65f2cbda0763dd` | 这笔交易的唯一编号 |
| From | Account 1 `0x3270b2B2558200e8b30898A9696D90c9591B3857` | 发送方 |
| To | Account 2 `0xa52b52465494934644c2195c3e71cE1fBF9ED610` | 接收方 |
| Value | 10 ETH | 转账金额 |
| 时间 | 2026-11-09 23:02 | MetaMask 显示 Confirmed |

## 4. 回执（eth_getTransactionReceipt）
| 字段 | 值 | 含义 |
|---|---|---|
| status | `0x1` | 1 = 成功 |
| blockNumber | `0x7`（区块 7） | 被打包进第 7 个区块 |
| transactionIndex | `0x0` | 该区块中第 1 笔交易 |
| gasUsed | `0x5208`（21,000） | 普通 ETH 转账固定消耗 21,000 gas |
| effectiveGasPrice | 1.393863558 Gwei | 实际单价 |
| 手续费 | 21,000 × 1.39 Gwei ≈ 0.0000293 ETH | gasUsed × 单价 |
| logs | 空 | 没有调用合约，不产生事件 |
| contractAddress | null | 不是部署合约的交易 |

## 5. 交易本身（eth_getTransactionByHash）
- nonce = 0：链重置后，这是 Account 1 发出的第一笔交易
- input = `0x`：没有调用数据，所以页面显示 “This transaction did not call any function”
- chainId = `0x7a69`（31337）：证明交易发生在本地链上
- type = `0x2`：EIP-1559 类型交易

## 6. 余额核对
- Account 2：10 ETH（等于转账金额）
- Account 1：约 19.99997 ETH（Faucet 转入 20 ETH − 10 ETH − 手续费）

## 7. 注意
- 前端右上角显示 “Wrong network”：说明网页连接的钱包当前不在 31337，切换到 Hardhat 即可；不影响 MetaMask 里的转账。
- 不要照抄网页上的主网参数，网络参数以本地终端输出为准。
